# Provisional Wingman identity

The original geometric wing is an engineering placeholder, not final cleared branding. No third-party logo artwork was copied. Name/trademark clearance and final brand review remain release work.

Flutter uses `WingmanMark`/`WingmanWordmark` in `lib/presentation/widgets/brand.dart`. Native app icons and the web favicon use the same geometry. Replace that widget and regenerate artwork with `swift scripts/generate_brand.swift` from the repository root. AppKit is only a developer asset-generation tool, not a runtime dependency.
