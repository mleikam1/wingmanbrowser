# Browser-readiness release gates

Reviewed September 12, 2026. This milestone starts from `13f8dfc` and prepares consumer version **0.12.0+12**, entry point `lib/main.dart`. This document separates source and host-test evidence from installed-app journeys. The final tested OS, engine, device and artifact identities belong in [DAILY_DRIVER_ACCEPTANCE.md](DAILY_DRIVER_ACCEPTANCE.md); the Android engine decision belongs in [ENGINE_DECISION.md](ENGINE_DECISION.md). Neither a simulator nor a test-owned WebView is physical consumer-device evidence.

**A production-ready claim remains blocked.** Known mandatory-category coverage gaps and Android resource-redirect enforcement are not closed by successful ordinary browsing or by a large unit-test count. The current UI appropriately explains that permitted destinations are not verified safe and that coverage is limited. Those disclosures are necessary, but do not satisfy the user's gate against known category-policy bypasses.

## What is permanently enforced

The immutable baseline is sequence 1, version `2026.9.11`, generated September 11 at 08:49 UTC. It contains **318,889** category/threat domain rules, **9** host/path rules and **2,501** tracker rules. Its 6,186,863 bytes are pinned by SHA-256 `f397d8f87a02fbb7754ce9c77931f740ba10271370e1e09f8402607bef59098f`. Dart and native code validate mandatory data; a failed baseline or uncertain native generation blocks protected browsing. Unknown destinations are permitted only when valid local policy has no match. User restrictions add denies and cannot subtract mandatory entries.

The first three large categories are HaGeZi NSFW, Gambling Mini and Threat Intelligence Mini adaptations. The latter two are deliberately upstream subsets. The remaining commercial-promotion categories are small hand-maintained supplements. Tracker rules are a licensed domain subset of EasyPrivacy, not its entire rule language. Source inputs, licenses and transformation are bundled, but a list's size or open-source license is not a guarantee of complete classification or an update service. The [HaGeZi project](https://github.com/hagezi/dns-blocklists) remains the upstream source; Wingman owns reviewing changes, corrections, attribution and redistribution obligations.

Validated data older than 24 hours is marked stale and continues blocking known entries during outages. It does not silently become an empty list. This differs from missing or corrupt policy, which closes browsing. The reviewed-site catalog's expiration and the school allowlist are separate from consumer navigation/search. See [PROTECTION_COVERAGE.md](PROTECTION_COVERAGE.md) and [CONSUMER_PROTECTION_UPDATES.md](CONSUMER_PROTECTION_UPDATES.md) for the exact coverage and update protocol.

The signed consumer update repository verifies purpose, signature, data digest, schema, release compatibility and monotonic sequence, stages a candidate, and requires independent native preparation and activation before acknowledging it. Host tests exercise corrupt, replayed, offline and failed-native paths. Production currently relies on reviewed application-bundle updates because no real feed or production trust root is provisioned. Do not describe this as an operating automatically maintained protection service.

Android's [WebViewClient contract](https://developer.android.com/reference/android/webkit/WebViewClient#shouldInterceptRequest(android.webkit.WebView,android.webkit.WebResourceRequest)) explicitly limits resource interception to the first URL in a redirect chain. Source checks at the start of that chain therefore do not prove enforcement on every hop. Replacing all normal networking with a simple URL fetcher would also need to preserve POST bodies, cookies, origin rules, cache, TLS and streaming; that is not a verified substitute.

The separate native HTTP-authentication callback supplies a hostname and realm. [Chromium's handler implementation](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/android_webview/browser/aw_http_auth_handler.cc) derives that value from the challenger's hostname, without passing its scheme or port to the app. A same-host comparison must not be described as a verified exact-origin challenge check.

Search uses `safe.duckduckgo.com`, strict `kp=1`, and disabled autocomplete preference `kac=-1`. Known provider entries and result wrappers are normalized before the ordinary destination decision. DuckDuckGo's [Safe Search documentation](https://duckduckgo.com/duckduckgo-help-pages/features/safe-search) supports the strict adult-filter choice and explicitly allows for missed content. The web companion can open that provider; after leaving the companion, the host browser owns navigation, cookies and protection. It is not a native Wingman browser on desktop.

## Source rights and freshness boundary

The rights decision remains limited to the publisher's own attributed factual text. [NASA's guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/) distinguishes factual/editorial use from endorsement and protected third-party material. [NOAA's reuse guidance](https://oceanservice.noaa.gov/about/faq.html) requires appropriate credit and prohibits misrepresentation or implied endorsement. [USGS copyrights and credits](https://www.usgs.gov/information-policies-and-instructions/copyrights-and-credits) distinguishes USGS public-domain work from protected contributions. None of these authorizes an arbitrary thumbnail or grants a worldwide blanket license to all government-hosted content.

The app renders bounded publisher excerpts and existing local category art, with no remote image fetch for cards. Thirty-minute ingestion and seven-day normalized cache retention are Wingman limits, not invented publisher terms. Conditional validation must honor server freshness/backoff. A client offline at the moment of a source withdrawal cannot know it immediately; finite cached-display expiry and revocation on reconnection remain required. Saved links do not authorize perpetual excerpt redistribution. See [CONTENT_SOURCES_AND_RIGHTS.md](CONTENT_SOURCES_AND_RIGHTS.md) and [CONTENT_OPERATING_COSTS.md](CONTENT_OPERATING_COSTS.md).
