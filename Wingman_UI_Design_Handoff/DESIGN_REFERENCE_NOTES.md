# Visual reference scope

This self-contained HTML file shows illustrative Wingman UI compositions, not a working browser or a runtime inspection of the GitHub application. Open the file locally in a browser; use the screen list, links, dark/light switch and wide preview. No installation or external assets are required.

The complete Codex prompt specifies all screens and states. The visual reference illustrates the main compositions; it is not an exhaustive interactive prototype of every dialog. Statuses, saved items, terms, domains and progress are synthetic design fixtures. Production controls must bind to actual capabilities and data. No website safety, review, encryption or network-audit claim follows from a mockup.

The logo crop removes only outer space and retains the raster background and highlights. The unchanged user-provided original is included. No font files are included.

The UI token pairs were checked with the WCAG relative-luminance formula, without opacity: white on #0062E8 ≈ 5.37:1; #54647B on white ≈ 6.02:1; #A9B9D0 on #101D31 ≈ 8.48:1; #071B4D on #79AAFF ≈ 7.08:1. These checks do not establish whole-interface accessibility; actual components, states, text sizes and composed surfaces still require testing.
